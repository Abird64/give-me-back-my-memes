# Design Context — 《把我的表情还回来！》

> 本文件是 emoji-migrator 前端的设计上下文，供 impeccable 工具集与后续会话复用。
> 位置说明：按 AGENTS.md §4 的写入白名单，仓库根目录仅 EM-008 可写，
> 故本文件置于 `design-prototype/`（规划产物区），不进入 `src/` / `tests/` / `docs/`。

## Users

- **谁在用**：普通用户（不是开发者），用微信 / QQ / 抖音聊天、收集表情包。
  技术小白，**零配置**是硬要求——文案不出现"种子密钥""WebP 转码""感知哈希"等术语。
- **情境**：在多个 App 之间搬表情时受阻——同一个表情在 A 端是动图、在 B 端变静态图、
  或者根本传不过去，于是攒了一堆表情却用不起来。
- **要完成的事**：
  1. 把三端（微信 / QQ / 抖音）里的表情捞出来，汇到一个地方；
  2. 像整理相册一样分类、筛选、挑选；
  3. 挑好的表情导出成目标端认得的格式，并知道怎么导回去。
- **情绪目标**：**"我的东西我拿回来"** 的爽感 + 一点恶作剧式的俏皮。
  不是冷冰冰的"文件转换器"，是**帮你把被平台扣下的表情要回来**。

## Brand Personality

**三个词：顽皮、干脆、怀旧**。

- 顽皮：标题本身就是一句带情绪的申诉——"把我的表情还回来！"
- 干脆：一屏一件事，大字大色块，不绕弯子，不用"向导""步骤"这类词。
- 怀旧：80/90 年代印刷海报与波普拼贴的语气，联想到旧贴纸册、街头海报墙。

## Aesthetic Direction

- **视觉方向**：**孟菲斯 / 80 年代波普拼贴（Memphis + Pop Collage）**。
  参照一张孟菲斯插画海报：紫粉渐变底、**纯黑粗描边**、**硬边偏移阴影（无模糊）**、
  复古浏览器窗口（顶部三色圆点）、半调网点、格纹、4 角星芒、斜置元素、太阳射线。
- **本产品继承的具体母题**（决定一切，不是泛泛"多彩"）：
  1. **复古浏览器窗口** → 直接作为三阶段流程的容器与导航（3 个窗口 = 3 个阶段）。
  2. **贴纸/剪贴册** → 相册页的表达：白边"模切"贴纸排成贴纸册页面。
  3. **海报标题块** → 产品名以倾斜色块 + 硬阴影呈现，配英文小标。
  4. **大箭头 / 杂技形状** → 用于指引与空状态。
- **配色**（token 化，非纯黑纯白）：
  - 墨线 `--ink: #1B1B1F`（近黑，非 #000）
  - 纸面 `--paper: #FFFCF5` / `--paper2: #F3EDDF`（暖白，非 #fff）
  - 紫 `--violet: #7C4DFF`、品红 `--magenta: #FF3D8F`、黄 `--yellow: #FFD23F`、
    青 `--teal: #15C4C4`、橙 `--orange: #FF7A2E`
  - 平台身份色沿用但改饱和：微信 `#2FBF71`、QQ `#1DA1F2`、抖音 `#FF2E4D`
- **字体**：ZCOOL KuaiLe（中文展示，仅主标题/大标题）、Noto Sans SC 400/500/700/900（中文正文与标题）、
  Archivo Black（拉丁字母与数字）。展示字与正文字严格分工，正文绝不用装饰体。
- **模式**：只做**亮色**。参考图气质依赖高明度底色，深色版会变成霓虹——那是 AI slop。
- **明确不要**：玻璃拟态、霓虹发光、暗底+紫蓝渐变、圆角+通用阴影、
  居中一切、每个元素都加渐变、emoji 直接当图标用（emoji 是**内容**，不是 UI 图标）。

## Design Principles

1. **一个屏幕一件事**。三个阶段 = 三个"窗口"，切换即换窗，不要把三件事塞进一屏。
2. **画布即相册**。相册是产品的主角，不是流程中的一站。表情以"模切贴纸"呈现，
   白边 + 黑描边 + 硬阴影，可拖可点可多选。
3. **装饰必须有出处**。半调网点、格纹、星芒、太阳射线全部来自参考海报母题，
   且只出现在**边角与留白**，不压在正文与操作区上。
4. **硬边硬影，全局统一**。3px 墨线 + 纯色偏移阴影（无模糊）贯穿所有卡片与按钮；
   任何一处圆角+柔和阴影都是设计漂移。
5. **反馈要有手感**。按钮按下时阴影收进、元素下沉 2px；贴纸选中回正并盖章。
6. **文案说人话**。正文 16px 起，元信息 ≥12px；不用技术黑话；
   导出的信息只写真实数字（文件数、去重数、目标端格式），不摆"质量档位"这类假控件。

## 落地约束（工程侧）

- 合规红线不变：9 个禁用 API 在 `src/` 零出现；本设计不新增任何 `ctypes` / `subprocess` 代码。
- 业务算法不重写：导出复用 `cli._normalize_dir`，采集复用 `wxcollect` / `collect_flow` / `qqdir`。
- **样式落地形态：已裁决为 `PySide6 壳 + QtWebEngine 承载 HTML`**（2026-10-21 人工确认）。
  理由：本风格依赖硬阴影、文字描边、半调网点、自定义展示字体、斜置拼贴——Qt QSS 实现不了；
  而 `douyin_auth` 已在用 `QWebEngineView`，依赖就位。落地见 `webui.py` 与 `docs/11-前端重构-*.md`。
- **字体必须本地化**：正式产品不联网，展示体按实际用字裁剪成 82KB / 5 个 woff2 随包分发；
  正文中文字用系统字体（微软雅黑 / PingFang）。原型阶段可用 CDN 便于评审。

## 交互与文案原则（补充）

- **渐进披露**：默认画面只给「支持 GIF / PNG」+ 一个问号；技术细节按需展开。
  小白不必先读技术说明。
- **不摆假控件**：任何看起来能调、实际不生效的东西一律删掉（质量档位已删）。
- **导出的信息只写真实数字**：文件数、去重数、目标端格式规则。
- **离线可用**：不依赖任何 CDN。
