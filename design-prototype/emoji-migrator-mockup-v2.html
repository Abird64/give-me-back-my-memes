📐 设计说明 / 这版改了什么 点开

1. 名字

产品名从「表情包互通」改成 《把我的表情还回来！》——从工具名变成一句情绪。 副标 GIVE ME BACK MY EMOJIS 保留了英文海报感。

2. 视觉母题直接取自参考海报

  • 复古浏览器窗口 → 三个阶段 = 三个窗口，顶栏三色圆点 + 地址栏，导航也是窗口标签。
  • 贴纸册 → 相册页做成一页活页贴纸册：装订孔、虚线、微微歪斜的模切贴纸。
  • 海报标题块 → 倾斜色块 + 3.5px 描边 + 硬阴影，像贴在墙上的海报。
  • 硬边阴影 → 全局 3px 墨线 + 纯色偏移阴影，零模糊、零圆角糖水。
  • 半调网点 / 星芒 / 格纹 / 太阳射线 → 只铺在边角留白，绝不压正文。

3. 逻辑修正（相对旧向导）

  • 旧的第 2 步「选平台」里塞着微信导出、抖音采集——采集是来源，不是目标。现在采集全在第 1 步，选平台只在第 3 步出现。
  • 质量档位假控件已删（旧版「仅作记录、不压缩」，EM-010 已下线档位常量）。导出信息改为真实数字：文件数、去重数、目标端格式。
  • 相册是主角：新增册页（分类）维度，可自建册页并把选中贴纸归进去。

4. 落地形态：这一版基本排除了 QSS 方案

本风格依赖硬阴影、文字描边、半调网点、自定义展示字体、斜置拼贴——这些在 Qt QSS 里几乎无法实现。 建议落地为 PySide6 壳 + QtWebEngine 承载本 HTML，而不是纯 QSS 重做。 需鹏子拍板。

5. 工程约束不变

  • 本文件是规划原型，不改 gui.py / src。
  • 落地时业务算法仍复用 cli._normalize_dir、wxcollect、collect_flow、qqdir，不重写。
  • 合规红线（9 个禁用 API 零出现）不变。
