# 把我的表情还回来 · 使用说明（小白版）

> 这份说明写给**不会写代码**的你。全程只要鼠标点点点，不用装任何东西。
> 工具本体就是一个 exe 文件：`把我的表情还回来.exe`。

## 这个工具是做什么的

你把电脑里的表情文件（微信收藏、QQ 收藏、或者任何文件夹里的图片）交给它，
它帮你做三件事：

1. **认格式**：自动看出每个文件*真正*是什么格式（很多文件后缀是错的，比如声明是
   `.jpg` 其实是 `.gif`）；
2. **改名整理**：把后缀改成正确的，去掉重复的表情；
3. **导出**：整理好的副本放到一个干净文件夹里，你手动导入到微信 / QQ / 抖音。

它**不压缩**你的图，**不改**你的原文件（原文件一个字节都不会动），
也**不会**替你点客户端的导入按钮——最后一步按下面的图文指引做，一分钟搞定。

## 怎么启动

双击 `把我的表情还回来.exe`。

- **第一次启动会等几秒**：这是正常的。单文件程序第一次运行要先在系统临时目录里
  解开自己（本机实测约 5 秒出窗口，取决于电脑快慢），之后会快一些。
- 启动后是一个三步向导窗口，跟着走就行。

## 三步向导

1. **第 1 步 · 选来源**：点「自动扫描本机 QQ 表情」（自动找到你电脑里的 QQ 收藏
   表情）；也可以把文件夹或图片文件直接拖进窗口，或用「添加文件夹…/添加文件…」。
   - 如果提示「没找到 QQ 表情目录」：请确认你**启动过 QQ 并打开过收藏表情**，
     然后再点一次扫描；也可以选手动添加。
2. **第 2 步 · 选平台和质量档位**：选你要导入到哪个端（微信 / QQ / 抖音）。
   质量档位默认「标准」——当前版本不做任何压缩，档位只是记录用，原图质量不变。
3. **第 3 步 · 导出**：点「开始导出」。导出的是**修正后的副本**，放在
   `C:\Users\你的用户名\emoji-migrator-out\日期时间\` 目录里（每次导出新建一个
   文件夹，不会覆盖上次的）。导出完成后点「打开导出目录」和「查看导入指引」。

## 导入指引（三步搞定）

导出完成后，点向导里的「查看导入指引」，会弹出对应平台的图文步骤。
文字版摘要：

### 导入微信

1. 打开微信，点左下角「我」→「表情」→ 右上角齿轮图标；
2. 点「添加单张表情」（或批量添加），选中导出的 `.gif` 文件，可一次多选；
3. 回到聊天窗口打开表情面板即可使用。
   **注意**：微信会自行压缩超大表情，可能把动图压成静态图——这是微信自身行为，
   本工具不做任何压缩。

### 导入 QQ

1. 打开任意 QQ 聊天窗口，打开表情面板，点左上角齿轮「设置」；
2. 选「导入导出」→「导入表情」，选中导出的目录或其中的 `.png` / `.gif` 文件；
3. 导入完成后打开「我的收藏」即可看到。QQ 会自己生成缩略图，原图不被改动。

### 导入抖音

1. 打开任意抖音聊天窗口，点输入框旁边的笑脸图标打开表情面板，再点左上角「+」号；
2. 在相册或文件列表里选中本工具导出的表情文件，可一次多选，抖音会逐个导入；
3. 回到聊天窗口打开表情面板即可使用。

## 怎么卸载

**删除 `把我的表情还回来.exe` 这一个文件就是完整卸载。**
本工具是单文件程序：不写注册表、不装服务、不在别处留文件（运行时临时解包的
文件在系统临时目录，重启后会自动清理）。

## 常见问题

**Q：杀毒软件提示有病毒/风险？**
A：本工具是 Python 打包的单文件程序，这类程序有时会被杀软启发式扫描误报。
本工具只做本地图片整理，不联网、不注入任何程序。如遇误报，请添加信任后使用；
该问题已登记待跟踪，不影响功能。

**Q：为什么我的动图导进去变成静态图了？**
A：平台（微信/QQ）会自动压缩表情，动图可能被压成静态图——这是平台行为。
本工具的导出环节不做压缩，动图进来是什么样、导出还是什么样。

**Q：导出的文件在哪？**
A：`C:\Users\你的用户名\emoji-migrator-out\` 下面的时间戳文件夹。向导第 3 步
的「打开导出目录」一键直达。

**Q：提示「没找到 QQ 表情目录」？**
A：请先启动过 QQ 并打开过收藏表情面板，再点一次「自动扫描本机 QQ 表情」。
实在扫不到就用「添加文件夹…」手动选。

**Q：质量档位选「高清」图会更大吗？**
A：不会。当前版本不做压缩，三个档位的输出完全一样，档位只是记录下来备查。
