## 1. 怎么跑（源码形态）

```bash
cd D:/code/mymeme
.venv/Scripts/python.exe -m emoji_migrator.gui
```

弹出「表情包互通 · 导入向导」窗口，三步走完即可（无需任何配置）。

## 2. 三步流程

1. **选来源**（`gui._SourcePage`）
   - 「自动扫描本机 QQ 表情」：走 D-07 两级探测链（见 §3）；
   - 拖拽：文件夹或图片文件都可以丢进列表（`gui._DropZone`）；
   - 「添加文件夹… / 添加文件… / 使用现有导出目录…」：后两者接受
     QQ 客户端手动导出过的目录、或命令行导出过的目录；
   - 「一键读取 TraceMemo 表情」：仅当 `%USERPROFILE%\Documents\TraceMemo\Emojis`
     存在时启用，缺失时**禁用**（点击零写入，有测试守门）。
2. **选平台**（`gui._PlatformPage`）：微信 / QQ 二选一；质量档位下拉框
   **默认预选「标准 standard」**（D-04 裁决 C，默认 B）。当前版本不做压缩，
   档位只作记录值写入导出日志（D-12/D-13 口径）。
3. **导出 + 指引**（`gui._ExportPage`）：默认导出到
   `~/emoji-migrator-out/<时间戳>/`（可改）。导出完成后「打开导出目录」
   与「查看导入指引」变为可用；正确性守门不通过时会弹警告并建议不要导入。

## 3. QQ 目录探测链（D-07 裁决 B，两级，只读）

```
① 注册表取安装目录（只读，标准库 winreg）
     主：HKLM\SOFTWARE\WOW6432Node\Tencent\QQNT 的 Install 值
         （2026-10-14 实测：D:\application\lnstallation\qq；
          HKCU\Software\Tencent\QQNT 只有 version，没有安装路径）
     兜底：HKLM\...\CurrentVersion\Uninstall\QQ 的
           DisplayIcon / UninstallString（取 exe 所在目录）
② 安装目录 → 聊天消息 → Tencent Files\*（QQ 号目录）
        → nt_qq\nt_data\Emoji\personal_emoji\Ori
```

- 找不到时：**不猜、不遍历全盘**，第 1 页显示中文报错
  「没找到 QQ 表情目录，请确认 QQ 已启动过并打开过收藏表情；也可以点
  『手动选择目录』自己指定。」并保留手动选择入口。
- 本机实测（2026-10-14，只读统计）：Ori 目录 **152 个文件**，后缀全为 `.jpg`，
  其中 52 个后缀错乱（49 实为 GIF、3 实为 PNG）。
- 验收数字按**不变量**断言，不硬编码 146/152：扫描到的目录全部受支持图片；
  规范化后错乱数 = 0；原动画 GIF 输出后仍动画（帧数 > 1）。

## 4. 导出为什么可信（复用，不重造）

GUI 不含任何嗅探/修后缀/去重/守门逻辑：

- 多来源（目录 + 零散文件）先由 `gui.stage_sources` 摊平暂存到系统临时目录
  （只收受支持图片、同名追加序号、原文件只读）；
- 再调用 `cli._normalize_dir`（EM-002 的受测编排）完成
  嗅探 → 后缀修正 → 感知哈希去重 → 正确性守门，stdout 重定向进 GUI 日志框；
- 输出目录与用户原文件**路径隔离**，产物是修正后的副本（逐字节复制，
  因此动图帧数结构性不可能丢失）。

## 8. 本包做的判断与可逆假设

1. **「使用现有导出目录」按「来源」实现**（接受 QQ 客户端手动导出过的目录 /
   命令行导出过的目录作为输入）。若原意是「跳过导出直接看已有产物」，
   改 `_SourcePage._choose_existing` 一处即可，可逆。
2. **质量档位当前只作记录**：本产品不做压缩（D-12/D-13），档位写入导出日志头。
   若未来接压缩，`run_export` 的 `tier` 参数已是现成入口。
3. **多来源走「临时目录摊平」再复用 CLI 管线**，而非在 GUI 里重写编排：
   保证 GUI 与命令行行为同构，代价是多一次磁盘复制。
4. **截图里的来源路径用占位符**（`D:\QQ\聊天消息\...你的QQ号\...`），
   不把真实 QQ 号/路径写进入库截图（隐私）。
5. **offscreen 中文渲染需显式加载系统字体**（实测 `QT_QPA_PLATFORM=offscreen` 下
   字体库为空，中文全成豆腐块）；该补救只在截图生成脚本里，产品代码不依赖它
   （真实显示环境字体库天然可用）。
6. 探测代码**没有**在测试里读真注册表（避免测试依赖本机 QQ 安装状态），
   用假 `winreg` 注入；结构守卫测试断言链的各级名字与实测一致。
