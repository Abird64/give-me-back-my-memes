# gmssl — BSD 许可证（登记说明与全文）

## 来源口径（如实声明，RUN-20261020-004）

上游项目 **duanhongyi/gmssl**（https://github.com/duanhongyi/gmssl ，PyPI 包名
`gmssl`）在其 PyPI METADATA 中声明 `License: BSD`，但**未随 wheel / sdist 分发
许可证全文**（wheel 3.2.2 与 sdist 3.2.1 均无 LICENSE/COPYING 文件，2026-10-20
实测核对）。GitHub 仓库同样未提供 LICENSE 文件。

因此本文件由两部分构成：

1. 上游声明原文摘录（可直接对账）；
2. 按上游「BSD」声明**对应的标准 BSD-3-Clause 条款文本**（本仓代录，版权归属行
   按上游 METADATA 的作者署名填写）。

本仓 vendored 文件 `src/emoji_migrator/_gmssl_sm3.py` / `_gmssl_func.py`
（gmssl 3.2.2 wheel 原样解出）随本分发受上述条款约束。
